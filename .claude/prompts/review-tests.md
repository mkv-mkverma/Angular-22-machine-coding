# Review Tests

Use the Angular Testing Agent.

Review the existing unit tests for the requested Angular file or feature.

Check:

- Are important behaviors tested?
- Are success and error cases tested?
- Are important branches tested?
- Are signals tested through behavior?
- Are dependencies mocked correctly?
- Are assertions meaningful?
- Are there duplicate or unnecessary tests?
- Are there missing edge cases?
- Are tests testing behavior instead of implementation details?

Do not modify production code.

Do not delete existing tests.

Report:

- Good tests
- Weak tests
- Missing tests
- Recommended improvements
